PART 0

Introduction ও Setup

Bootstrap কী, কেন, কীভাবে শুরু করবো – একদম গোড়া থেকে।

Bootstrap কী এবং কেন ব্যবহার করবো

সংজ্ঞা: Bootstrap হলো একটা ফ্রি, open-source CSS framework (তৈরি করা স্টাইলের ভান্ডার)। এতে আগে থেকে বানানো class, component (button, navbar, modal ইত্যাদি) আর JavaScript plugin থাকে, যা দিয়ে খুব দ্রুত responsive (সব স্ক্রিনে মানানসই) এবং mobile-first ওয়েবসাইট বানানো যায়।

কখন ব্যবহার করবো: যখন দ্রুত সুন্দর, responsive UI দরকার – যেমন admin panel, landing page, e-commerce frontend, prototype। Twitter-এর দুই developer (Mark Otto ও Jacob Thornton) ২০১১ সালে এটা বানিয়েছিলেন।

Bootstrap 5-এ jQuery বাদ দেওয়া হয়েছে, Internet Explorer সাপোর্ট নেই, আর v5.3-এ এসেছে color modes (dark mode) ও অনেক CSS variable।
Bootstrap হলো mobile-first, responsive ওয়েবসাইট দ্রুত বানানোর জন্য একটি open-source HTML, CSS ও JS framework।

কীভাবে ব্যবহার করবো: CDN vs npm vs Download

সংজ্ঞা: Bootstrap প্রজেক্টে আনার তিনটা উপায় – CDN (Content Delivery Network, অনলাইন লিংক), npm (Node package manager দিয়ে install), আর Download (zip ফাইল নামিয়ে লোকালি রাখা)।

CDN পদ্ধতি

npm পদ্ধতি

CSS লিংক দিলাম কিন্তু JS bundle দিলাম না – তাহলে navbar toggler, dropdown, modal কাজ করবে না!
CDN দ্রুত শুরু করার জন্য, npm customization ও বড় প্রজেক্টের জন্য, download অফলাইনের জন্য।

Environment Setup: VS Code, Live Server, Node.js, npm

সংজ্ঞা: কাজের পরিবেশ তৈরি করা – কোড লেখার editor, ব্রাউজারে অটো রিফ্রেশের টুল, আর package install করার জন্য Node.js।

ধাপে ধাপে

  1. VS Code install করো → Extensions থেকে Live Server install।
  2. Node.js LTS (nodejs.org) install করো।
  3. Terminal-এ ভার্সন চেক করো (নিচের কোড)।
  4. ফাইলে right-click → Open with Live Server।
VS Code-এ ! লিখে Tab চাপলে Emmet দিয়ে HTML boilerplate তৈরি হয়ে যায়।
Live Server অটো রিফ্রেশ দেয়, আর Node.js-এর সাথে আসা npm দিয়ে Bootstrap/Sass install করি।

Starter Template / Sandbox Setup

সংজ্ঞা: Starter template হলো Bootstrap চালানোর জন্য ন্যূনতম HTML কাঠামো। Sandbox মানে পরীক্ষা করার জায়গা – লোকালি একটা index.html, অথবা অনলাইনে CodePen/StackBlitz।
meta viewport ভুলে গেলে মোবাইলে পুরো ডেস্কটপ সাইট ছোট হয়ে দেখায় – breakpoint কাজ করে না।
Starter template-এ লাগে doctype, meta viewport, Bootstrap CSS (head) এবং bundle JS (body শেষে)।

Folder Structure (ফোল্ডার সাজানো)

সংজ্ঞা: প্রজেক্টের ফাইলগুলো সুন্দরভাবে আলাদা ফোল্ডারে রাখা, যাতে খুঁজে পাওয়া ও রক্ষণাবেক্ষণ সহজ হয়।
node_modules ফোল্ডার .gitignore-এ রাখো; অন্য কেউ npm install চালালেই আবার চলে আসবে।
HTML রুটে, CSS/JS/images আলাদা ফোল্ডারে; Sass ব্যবহার করলে scss ফোল্ডার থেকে css-এ compile হয়।

Bootstrap JS Bundle ও Popper

সংজ্ঞা: Popper হলো একটা ছোট library যা dropdown, tooltip, popover-কে সঠিক জায়গায় (position) বসায়। bootstrap.bundle.min.js ফাইলে Bootstrap JS + Popper দুটোই থাকে।
bundle আর আলাদা bootstrap.min.js দুটো একসাথে দিলে JS দুবার লোড হয় – dropdown দুবার toggle হয়ে কাজ করে না।
Popper dropdown/tooltip/popover-এর position ঠিক করে; bundle ফাইলে Popper আগে থেকেই থাকে।

data-bs-* Attributes

সংজ্ঞা: data-bs-* হলো HTML attribute যা দিয়ে কোনো JavaScript না লিখেই Bootstrap-এর JS component চালানো যায় (Data API)। v5-এ নামের আগে bs- যোগ হয়েছে (v4-এ ছিল data-toggle)।
v4 এর data-toggle লিখলে v5-এ কাজ করবে না – অবশ্যই data-bs-toggle।
data-bs-* attribute দিয়ে JavaScript না লিখেই HTML থেকে Bootstrap component নিয়ন্ত্রণ করা যায় (Data API)।
PART 1

Fundamentals (মৌলিক বিষয়)

Container, typography, utilities, breakpoint, button, navbar আর dark mode।

Containers

সংজ্ঞা: Container হলো সবচেয়ে বাইরের মোড়ক (wrapper) যা কনটেন্টকে মাঝখানে রাখে ও দুই পাশে padding দেয়। Grid ব্যবহার করতে হলে container লাগে।

কখন: প্রতিটা section-এর কনটেন্ট মাঝখানে সুন্দর প্রস্থে রাখতে container; পুরো স্ক্রিন জুড়ে (যেমন hero ব্যানার, ম্যাপ) container-fluid।

Container-এর ভিতরে আরেকটা container রাখা (nesting) দরকার নেই – এতে padding দ্বিগুণ হয়।
container fixed max-width দেয়, container-fluid সবসময় 100% প্রস্থ, container-{bp} নির্দিষ্ট breakpoint পর্যন্ত 100%।

Typography (লেখার স্টাইল)

সংজ্ঞা: Typography মানে heading, paragraph, font size, weight, alignment ইত্যাদি লেখার সাজসজ্জা।
text-truncate কাজ করতে element-কে display:block বা inline-block হতে হয় এবং প্রস্থ সীমিত থাকতে হয়। প্রোডাক্ট কার্ডের নামে খুব কাজের।
display-* বড় heading-এর জন্য, lead intro paragraph-এর জন্য; fs-* size আর fw-* weight বদলায়।

Display Utilities

সংজ্ঞা: d-* class দিয়ে element-এর CSS display property বদলানো যায় – দেখানো, লুকানো, flex/grid বানানো। Format: d-{breakpoint}-{value}।

কখন: মোবাইলে কিছু লুকাতে বা দেখাতে (যেমন মোবাইলে শুধু আইকন, ডেস্কটপে টেক্সট)।

“শুধু মোবাইলে লুকাতে” d-sm-none লেখা ভুল – এটা sm এবং তার উপরে লুকায়। মোবাইলে লুকাতে লেখো d-none d-sm-block।
d-none d-md-block মানে মোবাইলে লুকানো, md থেকে দেখানো – Bootstrap mobile-first বলে breakpoint “ঐ সাইজ ও তার উপরে” কাজ করে।

Position Utilities

সংজ্ঞা: CSS position ও স্থান (top/bottom/start/end) নিয়ন্ত্রণ করার class। Badge কে কোণায় বসানো, sticky header – এসবে লাগে।
Absolute element রাখতে চাইলে parent-এ অবশ্যই position-relative দাও – নইলে সেটা পুরো পেজ অনুযায়ী বসে যাবে। (Cart badge এভাবেই বানাবো!)
position-absolute top-0 start-100 translate-middle দিয়ে notification badge কে parent-এর উপরের-ডান কোণায় বসানো হয়।

Background ও Text Colors

সংজ্ঞা: Bootstrap-এর theme colors: primary, secondary, success, danger, warning, info, light, dark। এগুলো দিয়ে text-*, bg-*, btn-*, border-* ইত্যাদি তৈরি হয়।
bg-warning-এর উপর text-white দিলে পড়া যায় না (contrast কম)। text-bg-warning ব্যবহার করো – Bootstrap নিজেই ঠিক রং দেবে।
৮টা theme color আছে; text-bg-{color} background ও readable text color একসাথে সেট করে।

Spacing: margin, padding, gap

সংজ্ঞা: Format: {property}{sides}-{breakpoint}-{size}। property: m (margin, বাইরের ফাঁকা) / p (padding, ভিতরের ফাঁকা)। size 0–5 (0, .25, .5, 1, 1.5, 3rem) ও auto।
v4-এর ml-3, mr-3, pl-* v5-এ নেই! এখন ms-3, me-3, ps-*, pe-* (RTL ভাষা সাপোর্টের জন্য)।
Spacing format {m|p}{t|b|s|e|x|y}-{bp}-{0-5|auto}; v5-এ left/right এর বদলে start/end।

Sizing: width ও height

সংজ্ঞা: Parent-এর তুলনায় শতাংশে প্রস্থ (w-*) ও উচ্চতা (h-*) নির্ধারণ।
Login পেজ স্ক্রিনের মাঝখানে আনতে: d-flex align-items-center justify-content-center min-vh-100।
w-*/h-* parent-এর শতাংশ; vh-100/min-vh-100 পুরো স্ক্রিনের উচ্চতা।

Borders ও Rounded

সংজ্ঞা: Element-এর চারপাশে রেখা (border), তার রং, পুরুত্ব ও কোণ গোল করা (rounded)।
rounded-circle প্রোফাইল ছবি গোল করে, rounded-pill পিল আকৃতি দেয়; border-{1-5} পুরুত্ব।

Shadows

সংজ্ঞা: Element-এর নিচে ছায়া (box-shadow) দিয়ে উঁচু/ভাসমান ভাব আনা।
Product card-এ hover করলে ছায়া বাড়াতে নিজের CSS লেখো: .card:hover{box-shadow:var(--bs-box-shadow-lg)}।
Bootstrap-এ তিন মাত্রার shadow: shadow-sm, shadow, shadow-lg, আর shadow-none।

Breakpoints (xs থেকে xxl) – বাস্তবে ব্যবহার

সংজ্ঞা: Breakpoint হলো স্ক্রিনের সেই প্রস্থ যেখানে লেআউট বদলায়। Bootstrap mobile-first: class সেই breakpoint ও তার উপরের সব স্ক্রিনে কাজ করে (min-width media query)।

বাস্তব উদাহরণ: প্রোডাক্ট গ্রিড

মোবাইলে ২টা, ট্যাবলেটে ৩টা, ডেস্কটপে ৪টা প্রোডাক্ট এক লাইনে:

সবসময় আগে মোবাইলের class (col-12), তারপর বড় স্ক্রিনের (col-md-6) – এটাই mobile-first চিন্তা। DevTools-এ (F12 → Ctrl+Shift+M) device mode দিয়ে টেস্ট করো।
Bootstrap-এর ৬টা breakpoint: xs(<576), sm(576), md(768), lg(992), xl(1200), xxl(1400); এগুলো min-width ভিত্তিক তাই mobile-first।

Buttons

সংজ্ঞা: .btn base class + রঙের class দিয়ে সুন্দর বাটন। <button>, <a>, <input> – সবকটায় কাজ করে।
btn-primary লিখলাম কিন্তু btn দিলাম না – তাহলে padding, border-radius কিছুই আসবে না।
বাটনে সবসময় .btn base class + একটা variant (btn-primary/btn-outline-*) লাগে; size-এর জন্য btn-lg/btn-sm।

Navbar (Responsive, Toggler, Dropdown)

সংজ্ঞা: Navbar হলো সাইটের উপরের navigation bar। navbar-expand-{bp} বলে দেয় কোন breakpoint থেকে মেনু পুরো দেখাবে; তার নিচে hamburger toggler (☰) বাটনে collapse হয়।
Toggler-এর data-bs-target="#mainNav" আর collapse div-এর id="mainNav" হুবহু এক না হলে মোবাইলে মেনু খুলবে না। আর JS bundle না থাকলেও খুলবে না।
me-auto মেনুকে বামে রেখে বাকিটা ডানে ঠেলে দেয়; ms-auto দিলে মেনু ডানে যায়।
navbar-expand-lg মানে lg-এর নিচে মেনু collapse হয়ে toggler বাটনে চলে যায়; toggler কাজ করে data-bs-toggle="collapse" দিয়ে।

Dark Mode ও CSS Variables (data-bs-theme)

সংজ্ঞা: v5.3 থেকে color modes এসেছে। data-bs-theme="dark" attribute <html>-এ দিলে পুরো সাইট, আর কোনো element-এ দিলে শুধু সেই অংশ dark হয়। এটা সম্ভব হয়েছে CSS variables (--bs-*) এর কারণে।
Dark mode-এ bg-white/text-dark fixed রং – এগুলো বদলায় না। Theme-aware রং চাইলে bg-body, text-body ব্যবহার করো।
Bootstrap 5.3-এ data-bs-theme="dark" দিয়ে dark mode হয়, যা CSS variables (--bs-*) পরিবর্তন করে কাজ করে।
PART 2

Layout ও Components

Grid, flexbox, card, form, validation, table, pagination এবং দরকারি utilities।

Grid System: row, col, gutters

সংজ্ঞা: Grid হলো ১২ কলামের একটা লেআউট সিস্টেম, flexbox দিয়ে তৈরি। কাঠামো সবসময়: container → row → col। এক row-তে কলামের মোট মান ১২ হলে এক লাইন পূর্ণ।

কখন: পেজকে কলামে ভাগ করতে – sidebar + content, প্রোডাক্ট গ্রিড, footer-এর ৪ কলাম।

Background/border সরাসরি col-এ দিলে gutter-এর ফাঁকা দেখা যায় না। কনটেন্ট col-এর ভিতরের একটা div-এ রাখো। আর col সবসময় row-এর সরাসরি child হতে হবে।
Bootstrap grid ১২ কলামের, flexbox ভিত্তিক; গঠন container → row → col; gutter g-* দিয়ে নিয়ন্ত্রণ।

Grid Advanced: offset, order, nesting, auto-layout

সংজ্ঞা: Offset = বাম দিকে খালি কলাম রেখে সরানো; Order = দেখানোর ক্রম বদলানো; Nesting = col-এর ভিতরে আবার row; Auto-layout = সংখ্যা ছাড়া col দিলে সমান ভাগ।
Login form মাঝখানে আনতে: col-md-6 offset-md-3 অথবা row justify-content-center + col-md-6।
Offset কলামকে ডানে সরায়, order দেখানোর ক্রম বদলায়, nesting মানে col-এর ভিতরে নতুন row।

Flexbox Classes

সংজ্ঞা: d-flex দিয়ে flex container বানিয়ে child element-গুলোকে সারি/কলামে সাজানো, মাঝখানে আনা, ফাঁকা ভাগ করা।
justify-content-* বা align-items-* কাজ করছে না? Parent-এ d-flex দিতে ভুলে গেছো! আর align-items-center দেখতে parent-এর উচ্চতা থাকতে হয়।
কোনো কিছু একদম মাঝখানে আনতে: d-flex justify-content-center align-items-center।

Responsive Layout (বাস্তব প্যাটার্ন)

সংজ্ঞা: Grid + flex + display utilities মিলিয়ে এমন লেআউট যা মোবাইলে একভাবে, ডেস্কটপে আরেকভাবে সাজে।
ছবি responsive করতে সবসময় img-fluid (max-width:100%; height:auto)।
Responsive layout-এর মূল কৌশল: breakpoint-সহ grid class (col-md-*) + responsive utilities (d-md-*, text-md-*)।

Cards

সংজ্ঞা: Card হলো বর্ডার ও padding সহ একটা flexible বাক্স – ছবি, শিরোনাম, লেখা, বাটন রাখার জন্য। E-commerce-এর product card এটা দিয়েই।
Grid-এ কার্ডের উচ্চতা অসমান? প্রতিটা কার্ডে h-100 দাও। বাটন সবসময় নিচে রাখতে card-body-তে d-flex flex-column আর বাটনে mt-auto।
Card-এর মূল অংশ: card, card-img-top, card-body, card-title, card-text; horizontal card বানাতে card-এর ভিতরে row g-0।

List Groups ও Badges

সংজ্ঞা: List group = সুন্দর তালিকা (category list, cart item)। Badge = ছোট লেবেল বা সংখ্যা (নতুন, -২০%, cart count)।
List group তালিকার জন্য (list-group-item-action ক্লিকযোগ্য), badge ছোট গণনা/লেবেলের জন্য (badge text-bg-*)।

Forms ও Inputs

সংজ্ঞা: Bootstrap form controls ইনপুটগুলোকে একরকম, সুন্দর ও responsive করে – text, select, checkbox, switch, range, input group, floating label।
Floating label-এ placeholder attribute বাধ্যতামূলক এবং input আগে, label পরে আসতে হবে – নইলে label ভাসবে না।
লেবেলের for আর ইনপুটের id মিলাও – লেবেলে ক্লিক করলে ইনপুট focus হবে, আর accessibility ভালো হবে।
Text ইনপুটে form-control, select-এ form-select, checkbox-এ form-check-input; switch বানাতে form-check form-switch।

Form Validation ও Display

সংজ্ঞা: ইনপুট সঠিক কিনা চেক করে সবুজ (valid) বা লাল (invalid) দেখানো। Bootstrap HTML5 validation (required, type="email", minlength) ব্যবহার করে, আর submit-এ was-validated class যোগ করলে স্টাইল দেখায়।
invalid-feedback div-কে ইনপুটের ঠিক পরের sibling হতে হবে; মাঝে অন্য wrapper থাকলে বার্তা দেখাবে না (input-group-এ has-validation class লাগে)।
Form-এ novalidate + JS দিয়ে submit-এ checkValidity() চেক করে was-validated যোগ করলে valid/invalid-feedback দেখায়।

Alerts ও Progress Bars

সংজ্ঞা: Alert = ব্যবহারকারীকে বার্তা দেখানো (সফল, ভুল, সতর্কতা)। Progress = কতটুকু সম্পন্ন তা বার দিয়ে দেখানো (checkout step, skill bar)।
v5.3-এ role="progressbar" ও aria attribute গুলো বাইরের .progress div-এ দিতে হয়।
বন্ধযোগ্য alert: alert-dismissible fade show + btn-close-এ data-bs-dismiss="alert"; progress-এর প্রস্থ style="width:x%" দিয়ে।

Tables

সংজ্ঞা: <table>-এ .table দিলে সুন্দর স্টাইল আসে। Cart ও order history দেখাতে কাজে লাগে।
table-responsive সরাসরি table-এ দিলে কাজ করে না – table-এর বাইরের একটা div-এ দিতে হয়।
মোবাইলে টেবিল স্ক্রলযোগ্য করতে বাইরে div.table-responsive; table-striped ডোরা আর table-hover hover effect দেয়।

Breadcrumbs ও Pagination

সংজ্ঞা: Breadcrumb = ব্যবহারকারী সাইটের কোথায় আছে তার পথ (Home › Shoes › Nike)। Pagination = অনেক আইটেম পৃষ্ঠায় পৃষ্ঠায় ভাগ করা (Page 1, 2, 3)।
Breadcrumb পেজের অবস্থান দেখায় (breadcrumb-item), pagination পৃষ্ঠা ভাগ করে (page-item + page-link)।

অন্যান্য CSS Utilities

সংজ্ঞা: ছোট ছোট কিন্তু খুব কাজের helper class – ভিডিওর অনুপাত, লুকানো, স্ক্রল, স্তর (z-index), ছবি কাটা, স্বচ্ছতা ইত্যাদি।
invisible জায়গা দখল করে রাখে, d-none জায়গাসহ সরিয়ে দেয় – দুটো এক নয়।
ratio-16x9 ভিডিও responsive করে, object-fit-cover ছবি না চেপে কেটে বসায়, stretched-link পুরো কার্ড ক্লিকযোগ্য করে।
PART 3

Dynamic JavaScript Components

Dropdown, accordion, carousel, toast, modal, tooltip, offcanvas – সবকিছুর জন্য JS bundle লাগবে।

Dropdowns

সংজ্ঞা: বাটনে ক্লিক করলে নিচে একটা মেনু খোলে। Position ঠিক রাখতে Popper লাগে (bundle এ আছে)।
Popper ছাড়া শুধু bootstrap.min.js দিলে dropdown-এ error আসবে: “Bootstrap's dropdowns require Popper”।
Dropdown চালাতে data-bs-toggle="dropdown" লাগে এবং position এর জন্য Popper দরকার।

Collapse ও Accordion (Nested সহ)

সংজ্ঞা: Collapse = কনটেন্ট লুকানো/দেখানো। Accordion = অনেকগুলো collapse একসাথে, যেখানে একটা খুললে বাকিগুলো বন্ধ হয় (data-bs-parent)। FAQ, product description, filter-এ কাজে লাগে।
Nested accordion-এ ভিতরেরটার জন্য আলাদা id (#faqInner) ও আলাদা data-bs-parent দাও – নইলে ভিতরেরটা খুললে বাইরেরটা বন্ধ হয়ে যাবে।
Accordion-এ data-bs-parent নিশ্চিত করে যে একসাথে একটাই আইটেম খোলা থাকবে; এটা না দিলে সবগুলো স্বাধীনভাবে খোলে।

Carousel (Slider)

সংজ্ঞা: ছবি বা কনটেন্টের স্লাইডশো। Hero banner ও product gallery তে খুব ব্যবহৃত। Indicators (নিচের বিন্দু), controls (আগে/পরে তীর), captions (ছবির উপর লেখা), autoplay সব আছে।
কোনো carousel-item-এ active না থাকলে carousel কিছুই দেখাবে না! আর সব ছবির মাপ এক রাখো, নইলে উচ্চতা লাফাবে।
Carousel autoplay করতে data-bs-ride="carousel", সময় বদলাতে data-bs-interval; প্রথম স্লাইডে অবশ্যই active।

Toast Notifications ও Feedback UI

সংজ্ঞা: Toast হলো ছোট, হালকা নোটিফিকেশন যা কোণায় এসে কিছুক্ষণ পর নিজে চলে যায় – যেমন “Added to cart ✔”। Alert পেজের মধ্যে স্থির থাকে, toast ভাসমান ও অস্থায়ী। Toast অবশ্যই JS দিয়ে initialize করতে হয়।
Toast-এর HTML লিখে রাখলেই হবে না – Bootstrap performance-এর জন্য toast অটো চালু করে না, JS দিয়ে .show() কল করতে হয়।
Toast অস্থায়ী ভাসমান নোটিফিকেশন, যা bootstrap.Toast দিয়ে JS-এ initialize করে show() করতে হয়।

Spinners (লোডিং)

সংজ্ঞা: ডেটা লোড হওয়ার সময় ঘুরতে থাকা চিহ্ন – শুধু CSS দিয়ে তৈরি, JS লাগে না।
Order বাটনে ক্লিকের পর বাটনকে disabled করে spinner দেখাও – এতে ব্যবহারকারী দুবার অর্ডার দেবে না।
Spinner দুই ধরনের: spinner-border ও spinner-grow; accessibility-এর জন্য role="status" দিতে হয়।

Modals (Events, Dynamic Content, JS)

সংজ্ঞা: Modal হলো পেজের উপর ভেসে ওঠা dialog box (পপআপ)। Quick view, login, confirm delete, video – সব জায়গায় লাগে।

Dynamic content: একই modal-এ ভিন্ন প্রোডাক্ট

Modal-এর HTML অন্য কোনো position:fixed/relative element-এর ভিতরে রাখলে backdrop-এর পিছনে চলে যেতে পারে। Modal সবসময় <body>-এর কাছাকাছি (শেষে) রাখো।
show = খুলতে শুরু, shown = অ্যানিমেশন শেষ (input-এ focus দিতে এটা ব্যবহার করো); hide = বন্ধ শুরু, hidden = পুরো বন্ধ (ভিডিও থামাতে এটা)।
Modal-এর ৪টা প্রধান event: show.bs.modal, shown.bs.modal, hide.bs.modal, hidden.bs.modal; JS-এ bootstrap.Modal.getOrCreateInstance(el).show()।

Tooltips ও Popovers (JS initialization দরকার)

সংজ্ঞা: Tooltip = hover করলে ছোট লেখা। Popover = ক্লিক করলে শিরোনাম+লেখাসহ বড় বাক্স। দুটোই Popper ব্যবহার করে এবং performance-এর জন্য opt-in – মানে নিজে JS দিয়ে চালু করতে হয়।
সবচেয়ে কমন viva প্রশ্ন: “Tooltip কাজ করছে না কেন?” → কারণ JS দিয়ে initialize করা হয়নি অথবা Popper নেই। আর disabled বাটনে tooltip দিতে চাইলে বাটনকে একটা span-এ মুড়ে span-এ tooltip দাও।
Tooltip ও popover performance-এর কারণে opt-in, তাই new bootstrap.Tooltip()/new bootstrap.Popover() দিয়ে নিজে চালু করতে হয়।

Offcanvas Side Menu

সংজ্ঞা: Offcanvas হলো স্ক্রিনের পাশ থেকে স্লাইড করে আসা প্যানেল – মোবাইল মেনু, cart drawer, filter sidebar-এর জন্য খুবই জনপ্রিয়।
Responsive navbar-এ collapse-এর বদলে offcanvas ব্যবহার করলে মোবাইলে মেনু পাশ থেকে স্লাইড করে আসে – অনেক বেশি আধুনিক দেখায়।
Offcanvas স্ক্রিনের পাশ থেকে আসা লুকানো প্যানেল (offcanvas-start/end), খোলে data-bs-toggle="offcanvas" দিয়ে।

JavaScript দিয়ে Dark Mode Toggle

সংজ্ঞা: একটা বাটন চাপলে <html>-এর data-bs-theme attribute light ↔ dark বদলানো, আর পছন্দটা localStorage-এ সেভ রাখা যাতে পরে এলেও থাকে।
পেজ লোডের সময় সাদা ঝলক (flash) এড়াতে theme সেট করার ছোট script টা <head>-এ রাখো।
JS দিয়ে dark mode toggle করতে <html>-এর data-bs-theme বদলাই এবং localStorage-এ পছন্দ সেভ করি।
PART 4

Customization, Sass ও Icons

Bootstrap-কে নিজের ব্র্যান্ডের মতো বানানো – CSS override, CSS variables, Sass, Icons।

Bootstrap Customize করা (নিরাপদে Override)

সংজ্ঞা: Bootstrap-এর ফাইল সরাসরি না বদলে, নিজের CSS ফাইলে নতুন স্টাইল লিখে আগের স্টাইল “ঢেকে দেওয়া” (override)। CSS-এ যেটা পরে আসে ও যার specificity (নির্দিষ্টতা) বেশি, সেটাই জেতে।
Bootstrap-এর আগে নিজের CSS link করলে তোমার স্টাইল কাজ করবে না, কারণ Bootstrap পরে এসে override করে দেবে।
নিরাপদ customization মানে core ফাইল না বদলে, Bootstrap-এর পরে নিজের CSS/CSS variable বা Sass variable দিয়ে override করা।

CSS Variables দিয়ে Customization

সংজ্ঞা: CSS variable (custom property) হলো --নাম: মান; আকারে রাখা মান যা var(--নাম) দিয়ে ব্যবহার হয়। Bootstrap 5.3-এ প্রায় সব কিছুর জন্য --bs- prefix-যুক্ত variable আছে – root লেভেলে (global) ও component লেভেলে।
--bs-primary বদলালেই সব btn-primary বদলায় না – কারণ বাটনের রং compile-time-এ Sass দিয়ে তৈরি। পুরো theme color বদলাতে Sass ব্যবহার করো।
CSS variable রানটাইমে (browser-এ) বদলানো যায়, Sass variable compile-time-এ – তাই theme পুরো বদলাতে Sass, ছোটখাটো বদলাতে CSS variable।

Sass কী? (variables, nesting, partials, @use, maps, mixins)

সংজ্ঞা: Sass (Syntactically Awesome Style Sheets) হলো একটা CSS preprocessor – CSS-এর উন্নত রূপ যেখানে variable, nesting, function, mixin লেখা যায়। ব্রাউজার Sass বোঝে না, তাই এটাকে compile করে সাধারণ CSS বানাতে হয়। Bootstrap নিজেই Sass দিয়ে লেখা। ফাইল extension: .scss।
Partial ফাইলের নাম _ (underscore) দিয়ে শুরু, কিন্তু import করার সময় underscore ও .scss লিখতে হয় না।
Sass একটি CSS preprocessor যাতে variable, nesting, partial, map, mixin থাকে; এটা compile করে CSS বানাতে হয়।

Sass Install ও Setup (npm, compile/watch script)

সংজ্ঞা: npm দিয়ে sass package install করে package.json-এ script বানানো, যাতে এক কমান্ডে compile বা watch (ফাইল বদলালেই অটো compile) হয়।
HTML-এ .scss ফাইল link করা যায় না! সবসময় compile হওয়া css/main.css link করো।
VS Code-এ “Live Sass Compiler” extension দিয়েও compile করা যায়, তবে npm script পদ্ধতি প্রফেশনাল।
npm i -D sass দিয়ে install করে sass --watch input.scss:output.css দিয়ে অটো compile করি।

Bootstrap + Sass দিয়ে Customize (variables, theme colors, maps)

সংজ্ঞা: npm দিয়ে Bootstrap install করে, নিজের .scss ফাইলে Bootstrap-এর variable (যেমন $primary) import এর আগে বদলে দিলে compile হওয়া CSS-এ সব component নতুন রং/মাপ নেয়। Bootstrap-এর variable গুলোতে !default থাকে, তাই আগে সেট করা মান জেতে।

এখন btn-brand, text-brand, bg-brand class অটো তৈরি হবে! আর সব btn-primary কমলা হয়ে যাবে।

Accessibility (a11y) – aria attributes

সংজ্ঞা: Accessibility (সহজলভ্যতা) মানে এমনভাবে সাইট বানানো যাতে দৃষ্টি/শারীরিক প্রতিবন্ধী মানুষও screen reader ও keyboard দিয়ে ব্যবহার করতে পারেন। ARIA (Accessible Rich Internet Applications) attribute screen reader-কে বাড়তি তথ্য দেয়।
রঙের contrast ভালো রাখো (text-bg-* ব্যবহার করো), keyboard দিয়ে (Tab) পুরো সাইট চালিয়ে দেখো, আর শুধু রং দিয়ে অর্থ বোঝাবে না (লাল লেখার সাথে আইকন/লেখাও দাও)।
ARIA attribute (যেমন aria-label, aria-expanded) screen reader-কে element-এর নাম ও অবস্থা জানায়; visually-hidden লেখা শুধু screen reader পড়ে।

Bootstrap JavaScript API

সংজ্ঞা: data-bs-* ছাড়াও প্রতিটা JS component-কে JavaScript দিয়ে তৈরি ও নিয়ন্ত্রণ করা যায় – constructor, methods, options ও events দিয়ে। সব component bootstrap global object-এ থাকে।
একই element-এ বারবার new bootstrap.Modal() লিখলে একাধিক instance তৈরি হয়ে অদ্ভুত আচরণ করে – getOrCreateInstance ব্যবহার করো।
Bootstrap JS API-তে getOrCreateInstance() দিয়ে instance নিয়ে show()/hide()/toggle() method কল করি এবং *.bs.* event শুনি।

Performance Tips

সংজ্ঞা: সাইট দ্রুত লোড করার কৌশল – কম ফাইল, ছোট ফাইল, দেরিতে লোড।
Performance বাড়াতে minified ফাইল, lazy-loading ছবি, JS শেষে লোড, আর Sass দিয়ে শুধু দরকারি component import করি।

  2. Network tab: CSS/JS ফাইল 404 কিনা দেখো।
  3. Elements tab: element-এ class ঠিক আছে কিনা, কোন CSS কাটা পড়ছে (strikethrough) দেখো।
  4. Console-এ bootstrap লিখে Enter – object এলে JS লোড হয়েছে।
  5. Device toolbar (Ctrl+Shift+M) দিয়ে responsive টেস্ট।
Bootstrap JS কাজ না করার সবচেয়ে কমন কারণ: bundle JS না থাকা, ভুল order, বা v4-এর data-toggle ব্যবহার; ডিবাগ করি DevTools Console দিয়ে।

Bootstrap vs Tailwind CSS (Viva প্রশ্ন)

Bootstrap component-based (রেডি component + JS), Tailwind utility-first (নিজে utility দিয়ে ডিজাইন, JS নেই)।

🟢 Basic (১–২০)

Bootstrap কী?
Responsive, mobile-first ওয়েবসাইট দ্রুত বানানোর জন্য একটি ফ্রি, open-source CSS/JS framework।
Bootstrap কে বানিয়েছেন?
Twitter-এর Mark Otto ও Jacob Thornton, ২০১১ সালে।
Mobile-first মানে কী?
আগে ছোট স্ক্রিনের স্টাইল লেখা হয়, তারপর min-width media query দিয়ে বড় স্ক্রিনের জন্য পরিবর্তন।
Bootstrap যোগ করার উপায় কী কী?
CDN, npm install, আর ফাইল download করে লোকালি।
meta viewport tag কেন লাগে?
মোবাইলে পেজের প্রস্থ ডিভাইসের প্রস্থের সমান করে – এটা ছাড়া responsive breakpoint কাজ করে না।
container ও container-fluid-এর পার্থক্য?
container প্রতিটা breakpoint-এ fixed max-width, container-fluid সবসময় 100% প্রস্থ।
Grid-এ কত কলাম?
১২ কলাম।
Grid-এর মূল গঠন কী?
container → row → col।
Bootstrap 5-এর breakpoint কয়টা ও কী কী?
৬টা: xs(<576), sm(≥576), md(≥768), lg(≥992), xl(≥1200), xxl(≥1400)।
m-* ও p-* এর পার্থক্য?
m = margin (বাইরের ফাঁকা), p = padding (ভিতরের ফাঁকা)।
ms-auto কী করে?
বাম দিকে auto margin দিয়ে element-কে ডানে ঠেলে দেয়।
Theme color কয়টা?
৮টা: primary, secondary, success, danger, warning, info, light, dark।
Button বানাতে কোন class লাগে?
btn + একটা variant যেমন btn-primary বা btn-outline-primary।
d-none d-md-block মানে কী?
মোবাইলে লুকানো, md (768px) ও তার উপরে দেখাবে।
ছবি responsive করার class?
img-fluid (max-width:100%; height:auto)।
কোনো কিছু মাঝখানে আনার উপায়?
Block-এর জন্য mx-auto, লেখার জন্য text-center, flex-এ d-flex justify-content-center align-items-center।
display-* ও h1-এর পার্থক্য?
display-1…6 আরও বড় ও হালকা heading, hero section-এর জন্য।
Card-এর প্রধান অংশ কী কী?
card, card-img-top, card-body, card-title, card-text, card-header, card-footer।
Badge কী?
ছোট লেবেল বা গণনা দেখানোর component, যেমন cart count বা “New”।
Bootstrap Icons কীভাবে ব্যবহার করি?
CDN CSS যোগ করে <i class="bi bi-cart"></i> লিখি।

🟡 Intermediate (২১–৩৮)

Popper কী, কেন লাগে?
Dropdown, tooltip, popover-এর position হিসাব করার library; bundle ফাইলে আগে থেকেই থাকে।
bootstrap.bundle.js ও bootstrap.js-এর পার্থক্য?
bundle-এ Popper সহ থাকে, সাধারণ bootstrap.js-এ Popper নেই।
data-bs-* attribute কী?
JS না লিখে HTML থেকেই component চালানোর Data API, যেমন data-bs-toggle="modal"।
navbar-expand-lg কী করে?
lg ও উপরে মেনু পুরো দেখায়, তার নিচে collapse হয়ে toggler বাটনে চলে যায়।
Gutter কী? কীভাবে বদলাই?
কলামের মাঝের ফাঁকা; g-*, gx-*, gy-* দিয়ে।
Offset ও order কী?
offset কলামকে ডানে সরায় (offset-md-3), order দেখানোর ক্রম বদলায় (order-md-2)।
Nesting কী?
একটা col-এর ভিতরে নতুন row ও col রাখা।
row-cols-* কী?
row-এর সব child-কে সমান সংখ্যায় ভাগ করে, যেমন row-cols-md-3 = md থেকে প্রতি লাইনে ৩টা।
justify-content ও align-items এর পার্থক্য?
justify-content মূল অক্ষে (row-তে অনুভূমিক), align-items আড়াআড়ি অক্ষে (উল্লম্ব) সাজায়।
Accordion-এ data-bs-parent কেন?
একটা খুললে বাকিগুলো বন্ধ করতে – একসাথে একটাই খোলা থাকে।
Floating label কীভাবে বানাই?
form-floating div-এ আগে input (placeholder সহ), তারপর label।
Form validation কীভাবে কাজ করে?
form-এ novalidate, submit-এ JS দিয়ে checkValidity() চেক করে was-validated যোগ করলে valid/invalid-feedback দেখায়।
is-invalid কখন ব্যবহার করি?
ম্যানুয়ালি বা server-side validation-এর পর নির্দিষ্ট ইনপুট লাল দেখাতে।
Table মোবাইলে স্ক্রলযোগ্য করব কীভাবে?
table-এর বাইরে div.table-responsive দিয়ে।
Alert বন্ধযোগ্য করতে কী লাগে?
alert-dismissible fade show + btn-close-এ data-bs-dismiss="alert"।
Carousel autoplay ও সময় কীভাবে সেট করি?
data-bs-ride="carousel" ও প্রতিটা item বা wrapper-এ data-bs-interval="3000"।
Modal ও Offcanvas-এর পার্থক্য?
Modal মাঝখানে পপআপ, offcanvas স্ক্রিনের পাশ থেকে স্লাইড করে আসা প্যানেল।
sticky-top ও fixed-top-এর পার্থক্য?
fixed-top সবসময় উপরে আটকে কনটেন্ট ঢাকে; sticky-top নিজের জায়গায় থাকে, স্ক্রলে উপরে পৌঁছালে আটকে যায়।

🔴 Advanced (৩৯–৫০)

Tooltip/Popover কেন JS দিয়ে চালু করতে হয়?
Performance-এর জন্য এগুলো opt-in; new bootstrap.Tooltip(el) দিয়ে initialize করতে হয়।
Toast কীভাবে দেখাই?
bootstrap.Toast.getOrCreateInstance(el).show() – JS ছাড়া দেখায় না।
Modal-এর event গুলো কী?
show.bs.modal, shown.bs.modal, hide.bs.modal, hidden.bs.modal (আর hidePrevented.bs.modal)।
show ও shown event-এর পার্থক্য?
show খোলা শুরু হওয়ার সময়, shown অ্যানিমেশন শেষে পুরো খোলার পর ঘটে।
getInstance আর getOrCreateInstance-এর পার্থক্য?
getInstance আগের instance দেয় (না থাকলে null); getOrCreateInstance না থাকলে নতুন বানায়।
Bootstrap 5.3-এ dark mode কীভাবে?
data-bs-theme="dark" html বা কোনো element-এ; JS দিয়ে toggle ও localStorage-এ সেভ।
CSS variable ও Sass variable-এর পার্থক্য?
CSS variable ব্রাউজারে রানটাইমে বদলায়; Sass variable compile-time-এ, CSS-এ রূপান্তরের পর থাকে না।
Sass কী এবং এর feature?
CSS preprocessor; variable, nesting, partial, @use/@import, map, mixin, loop।
Sass দিয়ে Bootstrap-এর primary রং কীভাবে বদলাই?
Bootstrap import-এর আগে $primary: #রং; লিখে compile করি (কারণ Bootstrap variable-এ !default)।
!default flag কী?
Variable-এ মান আগে থেকে না থাকলে তবেই এই মান বসবে – তাই আমাদের দেওয়া মান জেতে।
Bootstrap 4 থেকে 5-এ বড় পরিবর্তন?
jQuery বাদ, IE সাপোর্ট বাদ, data-bs-*, left/right → start/end (ms/me), xxl breakpoint, offcanvas, utilities API; 5.3-এ color modes।
Bootstrap vs Tailwind?
Bootstrap component-based ও JS plugin সহ; Tailwind utility-first, JS নেই, সম্পূর্ণ কাস্টম ডিজাইনে সুবিধা।
